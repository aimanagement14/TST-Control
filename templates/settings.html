❓ ¿Cómo uso MiniMax Token Plan?

Importante: el Token Plan de MiniMax está pensado para generación de video (H3.0 / Hailuo-2.3), no para texto. Tu herramienta trabaja con texto, así que el Token Plan no aplica directamente.

Si MiniMax expone una API de texto con formato OpenAI-compatible (lo más común en proveedores modernos), puedes:

  1. Crear un preset con type=openai
  2. Poner el base_url que te dé MiniMax
  3. Pegar tu API key
  4. Indicar el nombre exacto del modelo
  5. Activar el preset

Si no estás seguro de los valores exactos, consulta la documentación de MiniMax para text LLM o usa el modo manual (puedes copiar los prompts a su interfaz web).

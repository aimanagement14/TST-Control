MiniMax: qué plan sirve para esta herramienta

El Token Plan de MiniMax está pensado para generación de vídeo (H3.0 / Hailuo-2.3). Esta herramienta sólo trabaja con texto, así que ese plan no aplica.

Si tienes acceso a su API de texto con formato OpenAI-compatible: crea un preset de tipo openai, pon la URL base y el modelo exactos que te indiquen, pega la clave y activa el preset. Si no, usa el modo manual y copia los prompts a su interfaz web.
